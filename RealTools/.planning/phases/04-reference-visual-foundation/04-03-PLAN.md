# Plan 04-03 - Feedback, Overlay, And Composite Primitive Styling

<objective>
Update feedback, overlay, and composite primitives so badges, dialogs, alert dialogs, toasts, and tag input chips follow the approved dark reference visual system while preserving existing behavior and APIs.
</objective>

<requirements_addressed>
UI-01, UI-04
</requirements_addressed>

<threat_model>
<threat id="T-04-03" severity="low">
Risk: Modal and toast visual changes can obscure critical destructive or error feedback.
Mitigation: Preserve dialog semantics and descriptive text, keep destructive states visually distinct through semantic token borders/text, and verify lint plus expected semantic class strings.
</threat>
</threat_model>

<must_haves>
<truths>
- Dialog and alert dialog exports must remain unchanged.
- Dialog titles must use `font-heading`.
- Toast styling must use CSS variables and semantic borders, not saturated fills.
- TagInput must preserve hidden JSON input, duplicate suppression, Enter/comma add behavior, and Backspace remove-last behavior.
- No Phase 4 file may add network, constellation, particle, or canvas background effects.
</truths>
</must_haves>
