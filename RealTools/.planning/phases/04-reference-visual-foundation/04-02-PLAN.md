# Plan 04-02 - Core Shared Primitive Styling

<objective>
Update the core shared primitives so buttons, cards, form controls, labels, and separators use the Phase 4 reference visual foundation: pill controls, dark surfaces, muted borders, accent focus, serif panel titles, and token-driven styling.
</objective>

<requirements_addressed>
UI-03, UI-04
</requirements_addressed>

<threat_model>
<threat id="T-04-02" severity="low">
Risk: Shared primitive changes can break form accessibility or existing component APIs.
Mitigation: Preserve all exported component names, Radix primitive structure, props passthrough, focus-visible classes, disabled states, and current variants while changing only class contracts.
</threat>
</threat_model>

<must_haves>
<truths>
- `components/ui/button.tsx` must keep `Button` and `buttonVariants` exports.
- `components/ui/button.tsx` must contain `rounded-full`, `h-11`, and `h-12`.
- `components/ui/card.tsx` must keep all Card family exports.
- Inputs, textareas, and select triggers must use `h-11` or equivalent 44px control height.
- Existing form control exports must not be renamed.
</truths>
</must_haves>

- .planning/phases/04-reference-visual-foundation/04-PATTERNS.md

<action>
Update `components/ui/button.tsx` while preserving `Button`, `buttonVariants`, the `asChild` API, `data-slot`, `data-variant`, and `data-size`:
1. Change the base class from `rounded-lg` to `rounded-full`.
2. Keep focus-visible, disabled, active translate, aria-invalid, SVG sizing, and transition behavior.
3. Set `variant.default` to `border-[#5f6575] bg-primary text-primary-foreground shadow-[inset_0_1px_0_rgba(255,255,255,0.12),0_18px_42px_rgba(0,0,0,0.22)] hover:bg-[#1d2332] hover:border-[#858a99]`.
4. Set `variant.outline` to `border-border bg-secondary/60 text-secondary-foreground hover:bg-muted hover:text-foreground aria-expanded:bg-muted`.
5. Set `variant.secondary` to `border border-border bg-secondary text-secondary-foreground hover:bg-muted`.
6. Set `variant.ghost` to `text-muted-foreground hover:bg-muted hover:text-foreground aria-expanded:bg-muted aria-expanded:text-foreground`.
7. Set `variant.destructive` to `border border-destructive/40 bg-destructive/10 text-destructive hover:bg-destructive/15 focus-visible:border-destructive/60 focus-visible:ring-destructive/25`.
8. Keep `variant.link`, but use `text-accent underline-offset-4 hover:underline`.
9. Change `size.default` to use `h-11 gap-2 px-5`.
10. Change `size.lg` to use `h-12 gap-2 px-7 text-base`.
11. Keep icon sizes stable and round icon buttons with `rounded-full`.
</action>
