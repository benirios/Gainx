# Plan 04-01 - Global Reference Tokens And Fonts

<objective>
Establish the global visual token layer for the reference-inspired dark UI: hex-based premium dark colors, serif display font wiring, muted foregrounds, focus tokens, and base styles. This plan must not restyle product pages directly and must not recreate the excluded reference background pattern.
</objective>

<requirements_addressed>
UI-01, UI-02
</requirements_addressed>

<threat_model>
<threat id="T-04-01" severity="low">
Risk: Global CSS changes can accidentally reduce readability or remove visible focus states.
Mitigation: Preserve focus-visible ring variables, define readable foreground/muted foreground values, and verify token strings with grep plus `npm run lint`.
</threat>
</threat_model>

<must_haves>
<truths>
- `app/globals.css` must contain `--background: #090d17`.
- `app/globals.css` must contain `--card: #111827`.
- `app/globals.css` must contain `--border: #2b3040`.
- `app/globals.css` must contain `--font-heading: var(--font-display)`.
- `app/layout.tsx` must import `Cormorant_Garamond` from `next/font/google`.
- No global CSS or layout code may implement network, constellation, particle, or canvas background effects.
</truths>
</must_haves>

<tasks>
<task id="04-01-01" type="execute">
<title>Wire root display font variable</title>
<read_first>
- app/layout.tsx
- .planning/phases/04-reference-visual-foundation/04-UI-SPEC.md
</read_first>
<action>
Update `app/layout.tsx`:
1. Change the import from `next/font/google` to import `Geist` and `Cormorant_Garamond`; remove the unused `Inter` import.
2. Keep `const geist = Geist({ subsets: ['latin'], variable: '--font-sans' })`.
3. Add `const cormorant = Cormorant_Garamond({ subsets: ['latin'], weight: ['400', '500', '600', '700'], variable: '--font-display' })`.
4. Set `<html lang="en" className={cn("dark", "font-sans", geist.variable, cormorant.variable)}>` so both font variables are available globally.
5. Set `<body>{children}</body>` and remove `inter.className` from the body.
</action>
<verify>
Run `npm run lint`.
Run `rg --fixed-strings -- 'Cormorant_Garamond' app/layout.tsx`.
Run `rg --fixed-strings -- '--font-display' app/layout.tsx`.
</verify>
<acceptance_criteria>
- `app/layout.tsx` contains `Cormorant_Garamond`.
- `app/layout.tsx` contains `variable: '--font-display'`.
- `app/layout.tsx` contains `geist.variable, cormorant.variable`.
- `app/layout.tsx` does not contain `Inter`.
- `npm run lint` exits 0.
</acceptance_criteria>
</task>

<task id="04-01-03" type="execute">
<title>Add base typography and background guardrails</title>
<read_first>
- app/globals.css
- .planning/phases/04-reference-visual-foundation/04-UI-SPEC.md
</read_first>
<action>
Update `@layer base` in `app/globals.css`:
1. Keep `* { @apply border-border outline-ring/50; }`.
2. Set `html { @apply font-sans; background: var(--background); }`.
3. Set `body { @apply bg-background text-foreground antialiased; font-size: 15px; line-height: 1.55; letter-spacing: 0; }`.
4. Add `h1, h2, h3, [data-slot="card-title"], [data-slot="dialog-title"], [data-slot="alert-dialog-title"] { font-family: var(--font-display), Georgia, serif; letter-spacing: 0; }`.
5. Add `::selection { background: color-mix(in srgb, var(--accent) 24%, transparent); color: var(--foreground); }`.
6. Do not add any `network`, `constellation`, `particle`, or `canvas` background selectors or classes.
</action>

</verify>
