## Interaction Contracts

### BuyersTable

- Row minimum height: 44px
- Actions column: two ghost icon buttons — `<Pencil size-4 />` (edit, opens BuyerFormModal prefilled) and `<Trash2 size-4 />` (delete, opens DeleteBuyerDialog). Icons visible at all times (not hover-reveal, unlike notes — table rows are a different affordance).
- Tags column: renders each tag as a `<Badge>` — `bg-zinc-700 text-zinc-300 text-xs rounded-full px-2 py-0.5`. Max 3 tags visible; overflow truncates silently (v1, no "+N more").
- Empty state: full-width centered block with `py-12`; heading "No buyers yet." (`text-base font-semibold text-zinc-50`); body "Add your first buyer to get started." (`text-sm text-zinc-400`); "New Buyer" button below.

### BuyerFormModal

- Create mode title: "New Buyer"
- Edit mode title: "Edit Buyer"
- Fields:
  - Name — `<Input>` — required — placeholder "Jane Smith"
  - Email — `<Input type="email">` — required — placeholder "jane@acme.com"
  - Tags — `<TagInput>` — optional — placeholder "Type a tag and press Enter"
- Validation: name required (min 1 char), email required (valid format). Field errors render as `text-sm text-red-500` below the input.
- Submit label (create): "Save Buyer"
- Submit label (edit): "Save Buyer"
- Cancel: ghost button "Cancel"
- Loading state: `<Loader2 className="mr-2 h-4 w-4 animate-spin" />` + "Saving…" on submit button; all fields disabled
- Success: modal closes + `toast.success("Buyer saved.")`

### TagInput (components/ui/tag-input.tsx)

- Renders existing tags as pills inside the input area: `bg-zinc-700 text-zinc-300 text-xs rounded-full px-2 py-0.5 flex items-center gap-1`
- Each pill has an `×` button (`text-zinc-400 hover:text-zinc-50`) to remove
- Text cursor follows pills; pressing Enter or comma commits the typed text as a new tag
- Empty typed text on Enter: no-op
- Duplicate tag: silently ignored
- Hidden `<input type="hidden" name="tags" value={JSON.stringify(tags)} />` serializes value for form action

### DeleteBuyerDialog

- Trigger: Trash2 icon button `h-8 w-8 text-zinc-400 hover:text-red-400`
- Title: "Delete Buyer?"
- Body: "This buyer will be permanently deleted." (`text-zinc-400`)
- Cancel: "Keep" — `border-zinc-700 text-zinc-50 hover:bg-zinc-800`
- Confirm: "Delete" — `bg-red-500 hover:bg-red-600 text-white`
- Loading state: `<Loader2 className="h-4 w-4 animate-spin" />` on confirm button; cancel disabled
- Success: `toast.success("Buyer deleted.")`
- Error: `toast.error("Failed to delete. Please try again.")`

### SendOmModal

- Trigger: "Send OM" button on Deal Hub — `bg-white text-zinc-950 hover:bg-zinc-100` — placed in Deal Hub header alongside deal title
- Modal: `sm:max-w-lg bg-zinc-900 border-zinc-800 text-zinc-50`
- Title: "Send OM"
- Description: "Select buyers to receive the OM link by email." (`text-sm text-zinc-400`)
- Body: scrollable checklist of all broker's buyers (`max-h-72 overflow-y-auto`)
  - Each row: `flex items-center gap-3 py-2 px-1`
  - `<Checkbox>` (shadcn) + buyer name (`text-base text-zinc-50`) + buyer email (`text-sm text-zinc-400`) + optional sent badge
  - Sent badge (if `om_sent_at` present): "Sent [Mon DD]" — `text-xs bg-zinc-700 text-zinc-300 rounded px-2 py-0.5 ml-auto`
  - Buyers with no previous send: no badge
- Empty buyer pool state: "No buyers yet. Add buyers from the Buyers page first." centered in the checklist area
- Submit: "Send to [N] buyers" — disabled when 0 checked — `bg-white text-zinc-950 hover:bg-zinc-100`
- Cancel: "Cancel" ghost button
- Loading state: "Sending…" + `<Loader2>` on submit; all checkboxes and Cancel disabled
- Success: modal closes + `toast.success("OM sent to [N] buyers.")`
- Error: `toast.error("Failed to send. Please try again.")`

### ActivityLogSection

- Section heading: "Activity" — `text-base font-semibold text-zinc-50`
- Positioned below FilesSection, same single-scroll layout
- No add/create action — read-only
- Events sorted descending (most recent first)
- Row format: `flex items-start gap-3 py-2 min-h-[44px]`
  - Timestamp: `text-sm text-zinc-400 w-36 shrink-0` — format "Apr 28, 2:30 PM"
  - Event description: `text-base text-zinc-50`
- Event copy (see Copywriting Contract below)
- Empty state: "No activity yet." — `text-sm text-zinc-400 text-center py-4` (consistent with NotesSection empty state pattern)
- Loading/polling: no skeleton — server component renders on load; `revalidatePath` refreshes after actions
