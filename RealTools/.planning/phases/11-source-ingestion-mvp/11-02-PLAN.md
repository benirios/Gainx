<objective>
Implement controlled OLX ingestion for configured listing import targets, using Phase 10 listing upsert helpers and Phase 11 import run status tracking.
</objective>

<threat_model>
Threats:
- HIGH: Running ingestion without authenticated user checks could write listings into the wrong account.
- HIGH: Unbounded scraping could hammer OLX or hang the app.
- MEDIUM: Scraper failures could crash the page instead of producing visible failed run status.
- MEDIUM: Extracted source URLs not normalized could break dedupe.

Mitigations:
- Server actions must use `supabase.auth.getUser()` and redirect unauthenticated users.
- Cap OLX runs with a small default/max listing count.
- No proxy rotation, CAPTCHA bypass, account login, or anti-bot evasion.
- Wrap scrape errors and record failed import runs.
- Use `upsertListing` for all saved listing records.
</threat_model>
