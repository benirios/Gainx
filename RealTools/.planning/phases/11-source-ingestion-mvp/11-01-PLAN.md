<objective>
Add durable ingestion run status so OLX and manual imports can report created, updated, skipped, failed, and error details per authenticated broker.
</objective>

<threat_model>
Threats:
- HIGH: Import run rows without `user_id`/RLS could expose one broker's source activity to another.
- HIGH: Status helpers that accept arbitrary user IDs from client input could forge run ownership.
- MEDIUM: Missing run status makes source failures invisible and blocks SRC-04.
- MEDIUM: Schema migration without push creates a false-positive implementation.

Mitigations:
- Add `user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE`.
- Enable RLS and owner-scoped policies.
- Only call helper functions from server actions after `supabase.auth.getUser()`.
- Include a blocking `supabase db push` task.
</threat_model>

      Create `supabase/migrations/009_listing_import_runs.sql` with `listing_import_runs`.

      Columns:
      - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
      - `user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE`
      - `target_id UUID REFERENCES listing_import_targets(id) ON DELETE SET NULL`
      - `source TEXT NOT NULL CHECK (source IN ('olx', 'facebook_manual'))`
      - `status TEXT NOT NULL DEFAULT 'running' CHECK (status IN ('running', 'completed', 'failed', 'partial'))`
      - `created_count INTEGER NOT NULL DEFAULT 0`
      - `updated_count INTEGER NOT NULL DEFAULT 0`
      - `skipped_count INTEGER NOT NULL DEFAULT 0`
      - `failed_count INTEGER NOT NULL DEFAULT 0`
      - `error_message TEXT`
      - `metadata JSONB DEFAULT '{}'::jsonb`
      - `started_at TIMESTAMPTZ DEFAULT now()`
      - `completed_at TIMESTAMPTZ`
      - `created_at TIMESTAMPTZ DEFAULT now()`

      Add RLS:
      - `ALTER TABLE listing_import_runs ENABLE ROW LEVEL SECURITY`
      - policy `Users can manage own listing import runs` for all operations using `auth.uid() = user_id`.

      Add indexes:
      - `idx_listing_import_runs_user_id`
      - `idx_listing_import_runs_target_id`
      - `idx_listing_import_runs_status`
      - `idx_listing_import_runs_created_at`

      Update `types/supabase.ts` with generated-style `listing_import_runs` Row/Insert/Update/Relationships.

      Create `lib/listings/import-runs.ts`.

      Export:
      - `startImportRun(supabase, userId, input)` inserts a running row and returns the row.
      - `completeImportRun(supabase, runId, userId, counts, metadata?)` updates the user's run to `completed` or `partial` when `failed_count > 0`.
      - `failImportRun(supabase, runId, userId, errorMessage, metadata?)` updates the user's run to `failed`.

      Types:
      - Use `Database['public']['Tables']['listing_import_runs']['Row' | 'Insert' | 'Update']`.
      - Use `Json` for metadata.

      Security:
      - Every update must include `.eq('id', runId).eq('user_id', userId)`.
      - Do not accept `user_id` from form data.
    </action>
