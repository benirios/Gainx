<objective>
Expose the ingestion MVP in the authenticated app: run OLX targets, import Facebook/manual CSV records, and review recent import status/failures.
</objective>

<threat_model>
Threats:
- HIGH: Manual import action without auth could let anonymous users write listings.
- HIGH: CSV source URL/title validation gaps could poison listing data and dedupe.
- MEDIUM: UI could trigger duplicate submissions without pending states.
- MEDIUM: Long URLs/errors could break the layout.

Mitigations:
- Server actions require `supabase.auth.getUser()`.
- CSV parser validates source URL and title through `ListingDraftSchema`.
- Client action buttons use pending/disabled state.
- UI truncates or wraps long strings.
</threat_model>
