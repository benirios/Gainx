<objective>
Refactor the dashboard and deal cards into a light, compact deal-management dashboard using only existing deal data.
</objective>

<threat_model>
Threats:
- MEDIUM: Dashboard summary cards could accidentally imply unsupported analytics if they display invented metrics.
- MEDIUM: Data query changes could show another user's deals or omit existing deal fields.
- LOW: Deal cards could lose the link to Deal Hub.

Mitigations:
- Derive summary cards only from `dealList`: total, active, negotiating, and closed counts.
- Preserve `.eq('user_id', user.id)` and selected fields in the dashboard query.
- Preserve `Link href={`/deals/${deal.id}`}` in `DealCard`.
</threat_model>
