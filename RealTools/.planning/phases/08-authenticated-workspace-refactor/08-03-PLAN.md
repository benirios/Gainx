</objective>

- HIGH: Changing Deal Hub queries could expose another user's deal or files.
- HIGH: Changing signed URL generation or file upload/delete paths could break private file access.
- MEDIUM: Changing note hidden input names or action bindings could break notes.
- MEDIUM: Removing activity formatting could reduce auditability.

- Preserve `.eq('id', id)`, `.eq('user_id', user.id)`, `.eq('deal_id', id)`, and `notFound()`.
- Preserve `createSignedUrl(f.storage_path, 3600)`.
- Preserve note and file server action imports, hidden inputs, and path format.
</threat_model>
