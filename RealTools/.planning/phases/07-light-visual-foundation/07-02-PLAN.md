# Plan 07-02: Action And Form Primitive Refactor

<objective>
Update shared action and form primitives to the light SaaS control language: 8px rounded controls, white surfaces, muted borders/text, purple focus/primary states, and preserved accessibility states.
</objective>

<requirements_addressed>
UI-06
</requirements_addressed>

<truths>
- Preserve all exported component names and props.
- Preserve `cva` variant APIs for buttons and Radix wrappers for select/checkbox/label.
- Do not change form serialization, validation logic, or keyboard behavior.
- Use lucide/Radix already present; add no new dependencies.
</truths>

<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| T-07-04: Styling changes break form accessibility states | MEDIUM | Preserve `focus-visible`, `disabled:`, `aria-invalid`, and `aria-expanded` classes and verify by grep. |
| T-07-05: Button variant API breaks downstream product components | MEDIUM | Keep existing variant names: `default`, `outline`, `secondary`, `ghost`, `destructive`, `link`; keep existing size names. |
| T-07-06: Form controls stop submitting values | LOW | Do not alter native input props, Radix component structure, hidden tag input serialization, or props spread. |
</threat_model>
