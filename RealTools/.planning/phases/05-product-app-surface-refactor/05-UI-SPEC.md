# Phase 05 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline metadata spacing |
| sm | 8px | Tight control groups, badge/tag inner spacing |
| md | 16px | Default field stack spacing, row content spacing |
| lg | 24px | Card/dialog inner padding |
| xl | 32px | Section spacing within Deal Hub/dashboard surfaces |
| 2xl | 48px | Major breaks between summary, notes, files, and activity |
| 3xl | 64px | Page-level vertical rhythm on desktop |

Exceptions: icon-only controls may be 32/36/40px; nav and interactive row targets must be at least 44px; modal max widths use stable content-fit tokens (`32rem`, `40rem`, `48rem`).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#090d17` | App background/page canvas |
| Secondary (30%) | `#111827` | Cards, dialogs, table/list containers |
| Accent (10%) | `#d7d1c4` | Focus rings, active nav state, primary emphasis borders |
| Destructive | `#ef6f6c` | Destructive actions and inline destructive feedback only |

Accent reserved for: focus-visible rings, active sidebar item text/border, Send OM primary emphasis border, and subtle premium dividers/highlights only.

---

## Visual Hierarchy & Focal Point (Authenticated Screens)

- Primary focal point: page header row (serif page heading + one primary action on the right, e.g., `Send OM` or `New Deal`).
- Secondary focal point: first data surface directly below the header (dashboard deal list/card group, or Deal Hub summary panel).
- Tertiary information (metadata, timestamps, helper copy, secondary actions) must remain visually muted to preserve scan priority for the first two focal layers.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Send OM` (Deal Hub primary), `New Deal` (dashboard creation), `Save Changes` (edit flows) |
| Empty state heading | `No deals yet` / `No buyers yet` |
| Empty state body | `Create a deal to start building the workspace, OM, buyers, and activity history in one place.` / `Add buyers once, then select them when sending an OM for a deal.` |
| Error state | `Something went wrong. Check the details and try again.` |
| Destructive confirmation | `Delete deal`: `This cannot be undone.`; `Delete buyer`: `This cannot be undone.` |
