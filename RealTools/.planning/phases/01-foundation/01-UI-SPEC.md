## Page Contracts

### Auth Pages (sign-in, sign-up)

Layout: Full viewport height, `flex items-center justify-center`, `bg-zinc-950`.

Structure (top to bottom):
1. "RealTools" text logo — 24px semibold, `text-zinc-50`, centered, 32px margin below
2. Card — `bg-zinc-900`, `border border-zinc-800`, `rounded-lg`, padding 32px, max-width 400px, width full
3. Inside card (top to bottom):
   - Page heading ("Sign in to your account" / "Create your account") — 20px semibold, `text-zinc-50`, 24px margin below
   - Email field (Label + Input) — 16px label, `type="email"`, `placeholder="you@example.com"`
   - Password field (Label + Input) — 16px label, `type="password"`, `placeholder="••••••••"`
   - Inline error zone — 14px `text-red-500`, appears below the specific invalid field via `FormMessage`
   - Submit button — full width, `bg-white text-zinc-950 hover:bg-zinc-100`, 16px semibold label
   - Toggle link — "Don't have an account? Sign up" / "Already have an account? Sign in" — 14px `text-zinc-400`, centered, 16px margin above

### App Layout Shell

Layout: `flex h-screen overflow-hidden bg-zinc-950`.

Sidebar:
- Width: 240px fixed, never collapsible in v1
- Background: `bg-zinc-950`
- Border right: `border-r border-zinc-800`
- Top section: App name "RealTools" — 20px semibold, `text-zinc-50`, 24px padding, 16px bottom margin
- Nav items (Deals, Buyers, Profile): 44px minimum height, `px-4 py-3`, `rounded-md mx-2`, `text-base text-zinc-400 hover:text-zinc-50 hover:bg-zinc-800`, active state `bg-zinc-800 text-zinc-50`
- Nav icons: Lucide React icons at 16px (`size-4`), 8px gap before label
- Bottom section: Logout button — `text-sm text-zinc-400 hover:text-zinc-50`, icon (LogOut from Lucide) + "Log out" label, 24px padding from bottom
- Sidebar divider (above logout): `border-t border-zinc-800`

Main content area:
- `flex-1 overflow-y-auto`
- Background: `bg-zinc-900` (distinguishes from sidebar)
- Padding: 32px

### Dashboard Placeholder Page

Content: Centered empty state inside main content area.

Structure:
- Heading: "Your deals will appear here." — 20px semibold, `text-zinc-50`
- Body: "Create your first deal to get started." — 16px regular, `text-zinc-400`, 8px below heading
- No CTA button in Phase 1 (Deal creation is Phase 2)

## Interaction Contracts

### Auth Form Validation

Library: react-hook-form + zod. Validation fires on submit (not on change, not on blur) to avoid premature error flash.

- Email field: required, valid email format (`z.string().email()`)
- Password field: required, minimum 8 characters (`z.string().min(8)`)
- On invalid submit: `FormMessage` renders below each invalid field in `text-red-500 text-sm`
- On server error (wrong credentials, email already exists): render error as a non-field `FormMessage` above the submit button, same `text-red-500 text-sm` style — do NOT use toast for auth form errors
- Submit button shows loading state during async: `disabled` + spinner icon (Lucide `Loader2` with `animate-spin`) replacing label

### Auth Redirects

| Event | Redirect destination |
|-------|---------------------|
| Successful sign-up | `/dashboard` |
| Successful sign-in | `/dashboard` |
| Successful sign-out | `/auth/login` |
| Unauthenticated visit to protected route | `/auth/login` |
| Authenticated visit to `/auth/login` | `/dashboard` |

### Sidebar Active State

Active nav item determined by current pathname. Use `usePathname()` from `next/navigation` in a Client Component wrapper for the nav. Route matching: exact match for `/dashboard`, prefix match for `/buyers` and `/profile`.

### Logout Interaction

- Logout button in sidebar bottom — single click, no confirmation dialog
- Calls sign-out Server Action, redirects to `/auth/login`
- No loading state required for logout (fast operation)
